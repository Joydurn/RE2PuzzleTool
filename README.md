# RE2PuzzleTool
Tool for RE2 remake speedrunners. Now Mobile-friendly c:  
Solve the puzzles as fast as you can, matching the 3 dials to the solution.  
Every time you load, the starting position is randomised.  

### GAUNTLET MODE: 
Cycle between the 3 medallions in order you would do them in the speedrun  
(A scenario: Lion-Unicorn-Maiden,  B scenario: Maiden-Unicorn-Lion)  

### Controls:
TOUCHSCREEN CONTROLS OR  
W and S or Arrow Up and Down to go up and down the dial  
A and D or Arrow Left and Right to switch dials  
Q,E ,F, or Left Click to complete puzzle  
R to reset  
P to clear PB  

### Other notes:
Tried to be close to the game feel of the inputs but do note its different in real game   
Super spagetti code so bugs here and there
